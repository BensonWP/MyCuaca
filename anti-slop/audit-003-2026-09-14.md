# Audit anti-slop 003, 2026-09-14

Level: fokus tema terang/gelap + kontras terhitung (contrast-check.py).
Cakupan: strategi `.dark` berbasis class, cakupan varian `dark:` semua komponen, pasangan teks kedua tema.

Semua temuan disetujui pengguna dan langsung diperbaiki.

## Temuan dan tindakan

[1] HIGH R-25: teks putih di atas `sky-600` pada dark mode gagal AA (4.10:1).
    Ditemukan di 3 lokasi (dua teridentifikasi saat audit, satu tertangkap saat verifikasi ulang):
    tombol lapisan aktif peta, link nav aktif desktop, dan tombol satuan aktif.
    SELESAI: ketiganya menjadi `dark:bg-sky-700` (putih di sky-700 = 5.93, lolos).

[2] MED I-5: fallback media query tanpa-JS menghasilkan tema gelap setengah (body gelap, komponen terang).
    SELESAI: blok fallback dihapus; tanpa JavaScript halaman selalu terang dan koheren.

[3] LOW G-6: placeholder input pencarian ikut warna default browser.
    SELESAI: `placeholder:text-zinc-500 dark:placeholder:text-zinc-400`,
    diverifikasi 4.83 (terang) dan 7.76 (gelap).

[4] LOW R-31: keputusan panel hero theme-independent belum tertulis.
    SELESAI: didokumentasikan di DESIGN.md.
